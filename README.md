# Mvalex Business Suite

Mvalex Business Suite is a comprehensive SaaS platform designed to empower businesses with professional-grade identity and financial tools. Built with modern web technologies, it provides an intuitive interface for creating business collateral without requiring design expertise.

## ✨ Core Features

- **🎴 Business Card Generator** - Create stunning, print-ready business cards with customizable templates, QR codes, and multiple export formats (PNG, PDF, DOCX)

- **📄 Invoice Generator** - Generate professional invoices with automatic calculations, multi-currency support, and various templates

- **🎨 AI Logo Generator** - Design unique brand identities using AI-powered logo generation with multiple style variations

- **🤖 AI Assistant** - Get intelligent guidance and recommendations for business design decisions

- **📊 Analytics Dashboard** - Track asset creation, monitor usage, and gain actionable insights

- **🔐 Enterprise Security** - Role-based access control, JWT authentication, and encrypted data storage

## 🏗️ Technical Architecture

### Frontend
- **Framework**: Next.js 14 (App Router)
- **Styling**: TailwindCSS + shadcn/ui
- **State Management**: TanStack Query
- **Animations**: Framer Motion

### Backend
- **API**: Next.js API Routes / NestJS
- **Database**: PostgreSQL with Prisma ORM
- **Authentication**: NextAuth.js
- **File Storage**: AWS S3 / Cloud Storage

### Key Technical Highlights
- ✅ Server-side rendering for optimal performance
- ✅ Real-time updates with WebSockets
- ✅ Responsive design for all devices
- ✅ Dark/Light mode support
- ✅ PWA ready
- ✅ 99.9% uptime SLA

npm run dev
